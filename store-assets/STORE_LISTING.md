# Chrome Web Store listing — RoFilter 1.2.0

## Name

RoFilter — Discovery Feed Filter

## Short description

Filter Roblox games by rating, active players and title keywords—then hide sponsored results for a cleaner Discover feed.

## Detailed description

Make Roblox Discover work your way.

RoFilter gives you simple controls for reducing unwanted game cards on Roblox Home and Discover. Choose your filters, save them, and keep browsing with less noise.

WHAT YOU CAN FILTER

• Minimum rating percentage
• Minimum active player count
• Words you do not want in game titles
• Sponsored game cards

WHY ROFILTER

• One focused purpose instead of a large feature bundle
• Simple settings that apply as new game cards load
• Open-source code you can inspect
• No collection of personal data, browsing history, or usage data by the developer
• No analytics, advertising SDK, or remote code

HOW TO USE IT

1. Install RoFilter and open Roblox in your browser.
2. Open the RoFilter toolbar panel.
3. Set the filters you want.
4. Select Save and apply.

RoFilter requests only the storage permission. Your settings are saved through Chrome sync; Apeira Studios does not receive them.

RoFilter is an independent project by Apeira Studios. It is not affiliated with, endorsed by, or sponsored by Roblox Corporation.

Source code: https://github.com/denizstudiox/RoFilter
